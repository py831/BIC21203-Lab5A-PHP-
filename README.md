## 2. Prerequisites & Setup
1. Install **XAMPP** (includes Apache and PHP) and **Visual Studio Code**.
2. Place or link the project folder inside your XAMPP `htdocs` directory (e.g., `C:\xampp\htdocs\WebDevLab\lab_5a`).
3. Open the **XAMPP Control Panel** and click **Start** on **Apache**.
4. Open the files in your browser via `localhost`:
   * `http://localhost/WebDevLab/lab_5a/lab5a_q1.php`
   * `http://localhost/WebDevLab/lab_5a/lab5a_q2.php`
   * `http://localhost/WebDevLab/lab_5a/lab5a_q3.php`
